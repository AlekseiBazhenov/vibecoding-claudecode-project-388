# Extract Price

Навык извлекает цены и сопутствующие данные товара с **одной** страницы по её URL.

## Контракт

**Вход:** один URL страницы товара (строка).

**Выход:** объект со следующими полями:

```json
{
  "name": "…",
  "regular_price": 0,
  "sale_price_regular": 0,
  "is_available": true/false
}
```

| Поле                      | Значение |
|---------------------------|----------|
| `name`                    | Название товара. |
| `regular_price`           | Обычная цена (число). |
| `sale_price_regular`      | Цена по скидке или `null`, если скидки нет. |
| `is_available`            | В наличии. |

Если какое-либо значение не найдено на странице — поставить `"-"`.

## Как искать цены

1. **Получить содержимое страницы.** Загрузить HTML по URL (например, через `curl`,
   `WebFetch` или HTTP-запрос из скрипта). При необходимости выполнить парсинг
   HTML (DOM), чтобы добраться до нужных элементов.
2. **Определить цены по визуальным/структурным признакам:**
   - **Обычная цена (`regular_price`)** — цена, показанная **не зачёркнутой**.
   - **Цена без скидки (`sale_price_regular`)** — цена **справа от обычной цены** (перечёркнутый текст: `<s>`, `<del>`, `<strike>`, `text-decoration: line-through`). Если цены без скидки нет — `null`.
3. **Извлечь `name` и `is_available`** из соответствующих элементов страницы
   (заголовок/название товара, строка с наличием).

## Нормализация значений

Для каждой найденной цены/числа:

- Убрать пробелы (в т.ч. неразрывные ` `), разделители разрядов и символы
  валюты (`₽`, `$`, `€`, `руб.` и т.п.).
- Заменить десятичную запятую на точку.
- Привести к числу (integer/float).
- Валюту при необходимости сохранить отдельно, а само значение хранить как число.

## Итог

- Каждое поле заполняется по правилам выше.
- Отсутствующее значение → `"-"`.
- Отсутствие скидки → `sale_price_regular = null`.
