# Skills

Эта папка — заготовка для будущих **Agent Skills** (навыков) Claude Code.

Каждый навык — это отдельная подпапка с файлом `SKILL.md`. Claude автоматически
подхватывает навыки из этой директории и использует их, когда описание навыка
совпадает с задачей пользователя.

## Структура

```
.claude/skills/
├── README.md                 # этот файл
└── <skill-name>/
    ├── SKILL.md              # обязательный: метаданные + инструкции
    ├── scripts/             # (опционально) вспомогательные скрипты
    ├── references/          # (опционально) справочные материалы
    └── assets/              # (опционально) шаблоны, ресурсы
```

## Как добавить новый навык

1. Создайте подпапку с понятным именем в kebab-case, например `my-skill/`.
2. Добавьте внутрь файл `SKILL.md` с YAML-фронтматтером (см. `example-skill/`).
3. В поле `description` чётко опишите, **когда** навык должен применяться —
   именно по нему Claude решает, использовать навык или нет.
4. Держите `SKILL.md` кратким; объёмные материалы выносите в `references/`.

Подробнее: https://code.claude.com/docs/en/skills
